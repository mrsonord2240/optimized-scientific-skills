# What to state

- The comparison: which level over which reference, and the design the script printed.
- Samples per level.
- The cutoff used (`padj < 0.05` unless the request set another) and the pre-filter (`min_count`).
- Genes tested, genes significant, and `padj = NA` by cause, each as its own number.
- Whether fold changes are the plain estimate or shrunken, and which method shrank them.
