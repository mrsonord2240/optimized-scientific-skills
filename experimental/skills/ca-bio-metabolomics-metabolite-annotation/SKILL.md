# Metabolite annotation

| Intent | Route |
|---|---|
| Match spectra to a local library | [Library](routes/library.md) |
| Rank candidates with MetFrag or adapt SIRIUS | [In silico](routes/in-silico.md) |
| Evaluate evidence and ambiguity | [Evidence](routes/evidence.md) |

Candidate rankings are hypotheses, not confirmed identities. Record evidence, alternatives, database versions and confidence limits; see [confidence notes](references/confidence.md) and [citations](references/citations.md). No scientific calculations were run during normalization.
