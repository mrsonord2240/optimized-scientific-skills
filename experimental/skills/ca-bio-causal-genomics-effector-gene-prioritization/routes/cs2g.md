# cS2G lookup

```bash
python scripts/cs2g_lookup.py cS2G_1000GEUR.zip 1 rs11206509 rs10788994
```

Use the chromosome and credible-set rsIDs from the user's data. The source table uses hg19 and 1000G EUR; check build and ancestry. See `references/cs2g-lookup.md`.

Done when SNP-gene scores, missing SNPs and summed ranking are reported.
