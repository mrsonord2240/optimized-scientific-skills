# Genome or gene packages

```bash
datasets download genome accession GCF_ACCESSION --include genome,protein,gff3 --filename genome.zip
```

Use a real accession or a taxon and select requested package contents. Check the installed Datasets CLI help for current syntax; validate package and manifest. Source alternatives and retrieval-size decisions are in `references/selection.md`; raw reads require the appropriate SRA workflow.

Done when the requested package and its integrity are verified and accession and version are recorded.
