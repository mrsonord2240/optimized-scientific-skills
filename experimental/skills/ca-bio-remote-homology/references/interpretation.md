# Method and version notes

GPTomics source describes profile drift from iterative inclusion, false matches from low complexity, and differences between sequence, profile and structure scores. The approximate twilight zone is not a binary homology test. Retain E-values, probability and coverage rather than claiming certainty; different tools' hit counts are not directly comparable. The source recommends inspecting inclusion sets and using matched profile database releases. Fold-level similarity alone is insufficient to establish homology. Versions cited by source: BLAST+ 2.15+, HMMER 3.4+, MMseqs2 15+, DIAMOND 2.1+, HH-suite3 3.3+ and Foldseek 9+. Check local help and data versions; these are historical compatibility claims, not fresh validation. The source reports Foldseek version in its no-argument banner rather than a `--version` flag. Related generic skills include `bio-blast-searches`, `bio-local-blast`, `bio-ortholog-inference`, and `bio-alignment-multiple`.
