# Interpretation and limits

GPTomics source describes Ensembl Compara tree-reconciled types and identity, OrthoDB hierarchical groups, OMA HOGs and strict pairwise calls, eggNOG functional groups, PANTHER least-diverged type, and pathway-centric KEGG KO assignments. Compara confidence may be absent; OrthoDB evolutionary rate is not a confidence score; OMA QC is not a per-call confidence field. Do not compare or average these fields. Orthologs do not necessarily retain identical function. Pin resource releases and normalize identifiers before comparing sets. Resolve renamed symbols first. OrthoDB search results are full-text matches and need membership verification. Retry transient errors and respect rate limits. The source client uses requests 2.31+, pandas 2.2+, a timeout and retries; its API checks are historical and require renewed verification. For more than roughly 5,000 genes, the source recommends BioMart rather than REST loops. A database missing a custom proteome requires de novo inference outside this skill.
