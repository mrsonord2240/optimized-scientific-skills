# API notes

GPTomics source describes the REST migration to `rest.uniprot.org`, nested JSON, selected TSV fields, search pagination versus stream, asynchronous ID mapping, isoforms, cross-references, UniRef clusters and proteome files. Search reads only one page; stream is held in memory. Mapping reads the stream and records unmapped IDs, but service behavior can change. Default canonical accessions differ from suffixed isoform accessions. UniProtKB combines reviewed and unreviewed entries; UniRef is clustered, UniParc archival, and Proteomes groups entries. `scripts/uniprot_client.py` uses requests 2.31+ and pandas 2.2+ with timeout and bounded retries. Source release observations are historical; check current schema, field names, limits and `X-UniProt-Release` when actually using the service.
