# Library suitability

| Chemistry | Action |
|---|---|
| 10X 3-prime | Sierra for APA; junction-supported pseudobulk only where sufficient support exists |
| 10X 5-prime GEX | Only 5-prime-proximal events; not transcriptome-wide |
| Smart-seq2/3, FLASH-seq, VASA-seq, STORM-seq | Full-length routes; account for UMI and nuclear/intron-retention context |
| Single-cell long reads | bio-long-read-splicing |

Do not promise transcriptome-wide cassette-exon PSI from 3-prime data. V(D)J requires a dedicated enriched assay. Done when the requested question is matched to the chemistry and a supported route.
