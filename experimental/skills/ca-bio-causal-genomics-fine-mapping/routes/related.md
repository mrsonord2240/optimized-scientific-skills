# Specialized cases

| Need | Skill or reference |
|---|---|
| Colocalization | bio-causal-genomics-colocalization-analysis and `references/coloc-susie.md` |
| HLA or long-range LD | `references/hla-long-range-ld.md` |
| Gene-level TWAS fine-mapping | bio-causal-genomics-transcriptome-wide-association |

Use in-sample genotype SuSiE when available. The source describes SuSiE-inf, FINEMAP-inf, CAVIAR, PAINTOR and MultiSuSiE as method choices but does not ship dedicated executable workflows.

Done when the specialized method is selected or the locus limitation is reported.
