# Access, size and source notes

The GPTomics source covers public SRA, ENA and STRIDES retrieval, not controlled-access authorization or credentials. An accession alone does not establish public status. For uncertain human access, establish public status or approved access with the user before attempting retrieval; do not bypass an access restriction or retry authorization failures as network faults. ENA missing FASTQ fields can indicate restricted access but is not conclusive.

Run IDs (SRR/ERR/DRR) identify retrieval units; experiment, sample, study and project IDs need metadata resolution. `prefetch` has a source-described 20G default limit; specify an appropriate bound and verify output. SRA and FASTQ sizes differ. `fasterq-dump` requires substantial uncompressed scratch and separate compression; the examples use pigz or gzip. Technical-read requirements vary by record. ENA and SRA may have different read counts; validate against the originating archive. `vdb-validate` checks SRA-format data; ENA publishes FASTQ MD5 values. Cloud region affects transfer cost. Source tested sra-tools 3.0+, pysradb 2.2+ and ENA portal API 2.0+; confirm installed flags and current service contract.
