# Matrix and denominator rules

GPTomics source maps missense and in-frame indels to Missense; nonsense, frameshift, nonstop and translation-start calls to Truncating; splice-site to Splice. Unmapped classifications are excluded and recorded on the matrix. The helper accepts separately normalized Amp, HomDel and Fusion calls, collapses duplicate classes and keeps multiple classes per cell. Explicit cohort IDs include zero-mutation samples and clinical annotations must be matched exactly, not positionally. ComplexHeatmap percentages use every input column even if empty columns are hidden. Its default row ordering counts alteration types; order by nonempty samples when prevalence is intended. maftools cannot add samples absent from the MAF and its black Multi_Hit is not the same as this palette's black Truncating. Source versions include ComplexHeatmap 2.22.0, maftools 2.22.0 and comut 0.0.3; check installed versions.
