# Mapping, background and reference

GPTomics source distinguishes pathway/module membership ORA, ranked GSEA and signed signaling-topology models. Query and measured universe must use matching IDs and a defensible eligibility definition; report unmapped and ambiguous conversions. Organism codes and bacterial locus tags are strain-specific, and a database join can fail without a useful result. Live KEGG queries change with time; a saved GSON snapshot can support reproducibility if the installed API and data terms permit it. An older internal database is not a current snapshot. GeneRatio is not fold enrichment; retain adjusted results and underlying counts. Topology methods may use different graph snapshots and do not necessarily score metabolic pathways or agree on direction. Overlap, enrichment and predicted perturbation are not independent proof of mechanism.
