# Metric and design choices

GPTomics source distinguishes observed features, Shannon and inverse Simpson, Faith PD, Bray-Curtis, Jaccard, weighted/unweighted/generalized UniFrac and compositional ordination. Observed ASVs are not necessarily species. Shannon log bases differ across implementations; convert consistently before comparing. Faith PD and UniFrac require a suitable tree; insertion and tree filtering can remove features. Rarefaction changes sample inclusion and is a method choice, not a universal remedy; retain raw counts for differential abundance. Report both depth and dropped samples. Compare reasonable metrics and tree choices without selecting solely by p-value. PERMANOVA can respond to dispersion as well as location; pair with a dispersion assessment and use exchangeable permutations appropriate to the design. Source package and CLI versions are historical; verify installed APIs. Related skills include `bio-microbiome-differential-abundance` and `bio-microbiome-amplicon-processing`.
