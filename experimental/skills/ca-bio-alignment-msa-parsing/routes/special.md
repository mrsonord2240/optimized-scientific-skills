# Specialized inputs and mapping

```bash
python scripts/content.py alignment.fasta results.json
```

| Need | Read |
|---|---|
| Stockholm annotation or residue/PDB coordinate mapping | `references/annotations-and-position-mapping.md` |
| Trimming and MUSCLE5 ensemble confidence | `references/trimming-and-reliability.md` |
| Ragged A2M/A3M or streaming large input | `references/a2m-a3m-streaming.md` |

For ragged or oversized data, use the relevant reference instead of the command above. Keep insert-state case in A2M/A3M.

Done when the requested positions, annotations, confidence, or match columns are obtained.
