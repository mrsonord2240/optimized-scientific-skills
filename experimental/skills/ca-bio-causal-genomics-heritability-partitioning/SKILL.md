# Heritability partitioning

Experimental. Paths are relative to this skill. Read the matching route and run its command before writing code.

| Need | Route |
|---|---|
| Total and partitioned LDSC | `routes/ldsc.md` |
| Tissue and cell-type enrichment | `routes/celltype.md` |
| LDAK comparison | `routes/ldak.md` |
| Local heritability | `routes/hess.md` |
| Individual genotypes | `routes/greml.md` |
| Genetic correlation or cross-population | `routes/correlation.md` |

Match ancestry and genome build to reference data. Report uncertainty, intercept, mean chi-square and ratio together; estimates are population-level research statistics, not individual clinical predictions.

Tested source versions include CBIIT LDSC 1f09cf0, LDAK 6.3, GCTA 1.94.1 and Popcorn 1.1.
