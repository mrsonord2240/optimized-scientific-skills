# LDAK SumHer

```bash
bash scripts/ldak_sumher.sh gwas_ldak.txt trait
```

Set LDAK_BIN, LDAK_TAGFILE and annotation/reference environment values to matching inputs. Script requires pre-QCed summary data and uses --check-sums NO. Compare enrichment with LDSC and report model dependence; see `references/ldak-sumher.md`.

Done when both model results and their assumptions are reported.
