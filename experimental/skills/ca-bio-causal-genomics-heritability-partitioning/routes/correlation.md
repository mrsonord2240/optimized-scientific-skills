# Genetic correlation

```bash
bash scripts/popcorn_rg.sh pop1_ref pop2_ref pop1.sumstats pop2.sumstats crosspop
```

This command is for distinct ancestry-matched population panels; consult `references/popcorn-transancestry.md` for source compatibility. Same-ancestry cross-trait LDSC and HDL options are in `references/cross-trait-ldsc.md` and `references/hdl-genetic-correlation.md`, or use bio-causal-genomics-genetic-correlation.

Done when correlation, uncertainty, overlap and reference limitations are reported.
