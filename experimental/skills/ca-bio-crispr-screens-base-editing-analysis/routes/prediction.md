# BE-Hive prediction

```bash
python scripts/behive_predict.py --behive-parent /path/to/clone-parent --spacer SPACER --pam PAM --upstream UPSTREAM --downstream DOWNSTREAM --editor BE4 --celltype mES > behive.txt
```

Replace placeholders with the user's inputs and matching model environment. The 50-nt substrate and offset requirements are in `references/be-hive-prediction.md`; predictions do not replace observed allele measurements.

Done when model inputs and predicted outcome table are documented.
