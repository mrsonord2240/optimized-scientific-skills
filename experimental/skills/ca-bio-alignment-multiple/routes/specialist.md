# Specialized alignment

```bash
t_coffee sequences.fasta -output fasta_aln -outfile aligned.fasta
```

For structure-aware or RNA modes and TCS use `references/tcoffee.md`. For fragmentary, very large, low-identity, pLM, joint tree/alignment or codon-pipeline work use `references/specialist-tools.md` and `references/selection.md`. Structural alignment is covered by `bio-alignment-structural`.

Done when a method suited to the data is selected and its requested output is produced.
