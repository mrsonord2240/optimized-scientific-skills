# Operations and assumptions

GPTomics source separates blank/detection filtering, within-batch drift, QC RSD/D-ratio filtering, between-batch alignment, imputation, sample normalization and transformation. QC correction assumes the pool tracks sample drift and requires sufficient bracketing QCs; weak QC signals and extrapolation undermine it. Biology confounded with order or batch cannot be recovered reliably by correction alone. Assess held-out QCs, dilution series and biological variability, not only fitted-QC clustering. TIC closure can spread a dominant feature's change. PQN assumes a stable majority; test factor relationships and corroborate with measured dilution rather than treating a single permutation result as proof. For missingness, distinguish plausible left-censoring from sporadic missingness; QRILC is applied on log2 values with a 2^x return to intensity scale, requiring positive observed values. Source thresholds are starting conventions: QC RSD 20–30%, D-ratio 0.5, blank ratio 3–5, detection 50–80%, and QC every 5–10 injections. Prespecify and report them, retaining feature counts. Source pmp QCRSC may return all-NA batches below minQC; inspect each batch. Confirm current package APIs and array orientation.
