# Background (not needed to run an analysis)

ORA is a competitive gene-sampling test. For each GO term, `enrichGO` computes the upper tail of the hypergeometric, `phyper(k-1, M, N-M, n, lower.tail=FALSE)`, the one-sided Fisher exact test on a 2x2 table. N = universe genes with any GO annotation, M = universe genes in the term, n = annotated foreground genes, k = overlap (`Count`). GeneRatio = k/n, BgRatio = M/N, fold enrichment = GeneRatio/BgRatio; both denominators count annotated genes only.

- The universe is the null distribution. Changing N or M changes every p-value. Omitting `universe=` makes N all annotated genes (about 18k for human BP); if the assay measured about 12k, terms for tissue-restricted and lowly expressed genes go spuriously significant. On null 150-gene lists against a 12k universe, omitting it added at most one marginal term (p.adjust 0.033) and often none (checked on clusterProfiler 4.14.6); the bias grows with the mismatch.
- ORA discards magnitude: a 2000-gene term at 1.2x fold can beat a 12-gene term at 4x on p alone.
- True-path propagation lights up a whole lineage from one signal; the tests are positively correlated, BH stays valid but the term list over-reports. `simplify()` collapses by semantic similarity within one ontology; `ont='ALL'` objects are split per ontology by `simplify_ALL()` internally (checked on 4.14.6). `measure='Wang'` is topology-based and stable across annotation releases; IC-based measures shift with the corpus. topGO elim/weight01 decorrelates inside the test; treat its scores as a ranking, not calibrated FDR.
- DE detection power scales with read count, which scales with length and expression, so the foreground is enriched for long genes. GOseq fits a probability weighting function over length and tests with the Wallenius noncentral hypergeometric.
- ORA versus GSEA: all genes with a statistic and an arbitrary cutoff favour GSEA; a pre-selected list with no ranking favours ORA; very small lists have little power.
- Thresholds: `pvalueCutoff=0.05` and `qvalueCutoff=0.2` (clusterProfiler defaults, filtering `p.adjust`), BH, `minGSSize=10`, `maxGSSize=500`, `simplify(cutoff=0.7)`, fold enrichment above 2 as a rough flag only, ID loss above 15% as unreliable.
- The source reference scripts for the basic and all-ontology runs drew toy gene lists from org.Hs.eg.db; `scripts/ora_go.R` replaces them.
