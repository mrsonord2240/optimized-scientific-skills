# Method selection and caveats

A mask combines functional annotations and an allele-frequency cutoff; it defines the hypothesis. Burden tests collapse effects and can lose power when directions cancel. SKAT uses a variance-component score and accommodates mixed directions; SKAT-O combines the two across a rho grid. ACAT-V/ACAT-O combine p-values and can be dominated by one artifact. STAAR incorporates multiple functional annotations; this source supplies no runnable STAAR workflow. Match the method to the effect architecture and review influential variants.

Imbalanced binary traits and low minor-allele counts require appropriate tail calibration, such as the source's SAIGE SPA or regenie Firth/SPA paths. Relatedness and structure require a suitable null; PCs alone do not model relatedness. Apply genotype and imputation-quality QC before creating masks and inspect calibration and sample alignment. Source conventions include MAF tiers 0.0001, 0.001 and 0.01, INFO/R2 at least 0.8 for rare imputed variants, and Beta(1,25) SKAT weights. These are examples, not universal thresholds. The source cites a regenie ultra-rare MAC threshold of 10 and warns that `.all` and singleton masks have distinct semantics; check the installed release.

Each gene-by-mask test contributes to multiplicity unless properly combined into a prespecified omnibus family. The illustrative 0.05/20,000 = 2.5e-6 threshold assumes 20,000 gene tests and needs adjustment for the actual family and additional masks. Retain counts, masks, cutoffs, variant QC, null covariates, sample order, software versions, test statistics and calibration diagnostics. Empty masks can result from mismatched IDs; run the source regenie burden-file check before modeling. An apparent hit can be driven by one miscalled variant; inspect it. Single-variant tests need a separate workflow; see `bio-causal-genomics-fine-mapping` for follow-up.
