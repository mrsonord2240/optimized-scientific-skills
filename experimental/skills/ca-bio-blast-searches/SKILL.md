# Remote BLAST search

Choose and read a route, then run its command before writing code. Paths are relative to this skill.

| Need | Route |
|---|---|
| DNA, protein or translated remote search | `routes/search.md` |
| Resume or retrieve a search by RID | `routes/rid.md` |
| Parse and interpret saved results | `routes/results.md` |

Use a named FASTA query, choose matching query and database molecule types, and record database and search date. GPTomics bioSkills, MIT, upstream d91ed3d563019e649dc854c56ccd62551359488a.

Source checked Biopython 1.83+ and BLAST+ 2.15+; remote service behavior may change.
