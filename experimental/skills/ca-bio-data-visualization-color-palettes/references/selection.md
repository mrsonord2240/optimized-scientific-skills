# Palette selection

Sequential data suit viridis, cividis, magma, batlow or lipari; diverging data suit vik, roma or RdBu with an explicit reference and suitable bounds; cyclic quantities need a wraparound palette such as romaO; nominal categories need a named qualitative mapping. The source Okabe-Ito chromatic colors are `#E69F00`, `#56B4E9`, `#009E73`, `#F0E442`, `#0072B2`, `#D55E00`, `#CC79A7`, with `#BBBBBB` reserved for unassigned. The source uses Up `#D55E00`, Down `#0072B2`, NS `#999999`. ColorBrewer and journal palettes may need additional CVD checks. Rainbow, jet and turbo have nonmonotonic luminance. Built-in diverging centers may be tinted, not pure white. Nonzero references require explicit normalization and valid bounds on both sides; mask nonfinite values and label missingness separately. For 9–20 categories use redundant encodings and consider faceting; for more reconsider the design. Source versions are historical: viridis 0.6.5, scico 1.5.0, colorspace 2.1.2, RColorBrewer 1.1.3 and ggsci 5.2.0; confirm local APIs.
