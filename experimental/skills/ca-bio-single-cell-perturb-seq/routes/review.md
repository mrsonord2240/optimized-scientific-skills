# Inference and evaluation
SCEPTRE requires aligned response and guide matrices, controls, covariates, prespecified pairs and a meaningful calibration assessment before discovery. The source example is packaged-data only; nonempty calibration results alone do not prove calibration. A study-specific workflow must evaluate calibration diagnostics before proceeding. E-distance is embedding-dependent; condition or target comparisons need independent replication and multiple-testing review. Separate state-composition change from within-state expression and use raw-count pseudobulk for replicate-aware analysis. See [methods](../references/methods.md).
