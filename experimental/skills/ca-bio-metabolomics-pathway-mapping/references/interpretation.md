# Background and uncertainty

GPTomics source distinguishes ORA on identified hits with an assay-coverage universe, rank-aware MSEA/QEA, PSEA on the full feature table, and network diffusion. Annotation uncertainty can propagate into apparently precise enrichment p-values; retain alternative IDs and avoid counting one ambiguous feature as several confirmed compounds. Pathway topology impact can be dominated by hubs and is not an effect size. Pathway definitions and database coverage affect results. Concentration or pool enrichment alone does not establish pathway flux. Report input coverage, ion mode, mass tolerance, query cutoff, tested family, correction, unmapped features and source versions. Source MetaboAnalystR 4.3 local sessions require initializing `current.msg` and `err.vec`; public library downloads and remote API behavior were historically observed and should be verified before use. A generic reference fetch still requires network access, while the API ORA sends user compound data.
