# CREST sampling

```bash
crest input.xyz --gfn2 -T 12
```

Use an appropriately prepared initial geometry and validate results for the chemistry. On native Windows use a supported Linux environment for CREST or the documented RDKit and standalone xTB alternative. See `references/crest.md` and `references/troubleshooting.md`.

Done when the ensemble and run settings are saved and convergence assessed.
