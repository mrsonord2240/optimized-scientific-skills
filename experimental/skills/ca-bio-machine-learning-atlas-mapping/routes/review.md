# Mapping limitations and alternatives
Nearest-reference labels can be confidently wrong for absent or neighboring types. Neighbor-label disagreement measures label ambiguity, not a complete distance-based OOD test; use reference-matched validation, held-out labels and independent marker/QC checks. Symphony, Azimuth, scPoli, popV, treeArches and classifier-only alternatives need their own prepared references and workflows. See [methods](../references/methods.md).
