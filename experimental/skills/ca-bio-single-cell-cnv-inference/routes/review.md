# Allele-aware analysis and interpretation
Numbat requires study-specific BAMs, allele counts, phasing resources, genome build and a matched normal expression reference. The source provides preprocessing and model patterns in [methods](../references/methods.md), but not a complete file-based pipeline here; validate the required inputs and installed API before adapting it. Infer per patient before cross-patient integration. Reference contamination, sex mismatch, lineage-linked expression, low coverage, CNV-quiet tumors and balanced whole-genome doubling can mislead expression-only inference. Flat profiles do not establish normality, and subclones need orthogonal DNA, allele or lineage evidence.
