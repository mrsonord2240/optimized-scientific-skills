# Encoding and corrections

GPTomics source describes uniform-background information `log2(K) - H(p)` versus probability stacks, and relative entropy `D_KL(p || q)` with letter height `p_i D_KL`. The supplied helper uses raw observed probabilities and no smoothing. ggseqlogo sequence-vector bits applies a small-sample correction; a supplied matrix lacks sample size and does not receive that correction. Logomaker's default pseudocount of one is different; WebLogo uses a prior. State the actual parameters and do not claim background correction for a uniform calculation. Verify equal lengths, matrix orientation and alphabet; ggseqlogo uses letters by position while Logomaker uses positions by letters. DNA maximum uniform-background information is 2 bits and protein approximately 4.32. N below five is exploratory; N of 20 or more is a practical guide, not proof of robustness. Source checked ggseqlogo 0.2, Logomaker 0.8+ and WebLogo 3.7+; confirm local versions. WebLogo image output on Windows may require Ghostscript.
