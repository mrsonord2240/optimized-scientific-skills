# Interpretation and methods

GPTomics source describes ALDEx2, ANCOM-BC2, LinDA, MaAsLin2/3, ZicoSeq and exploratory LEfSe; input orientation, zero handling and adjustment defaults differ. Prevalence filtering changes the tested family and can remove rare taxa. Relative abundance is compositional and cannot establish absolute change without an appropriate external load measurement. Repeated measures need a model for subject dependence. ALDEx2 uses count data and its `we.eBH` is the expected adjusted Welch result; source thresholds of 0.05 and effect > 1 are choices, not universal truth. ANCOM-BC2 sensitivity flags help identify pseudo-count-sensitive results. Report each method's full results and uncertainty; agreement or intersection across methods does not guarantee correctness. Source package versions are historical and APIs require verification.
