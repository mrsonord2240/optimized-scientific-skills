# Genetic correlation

Experimental. Paths are relative to this skill. Read the matching route and run its command before writing code.

| Need | Route |
|---|---|
| Global same-ancestry correlation | `routes/ldsc.md` |
| HDL with known independent samples | `routes/hdl.md` |
| Local correlation | `routes/local.md` |
| Cross-population correlation | `routes/popcorn.md` |
| Individual-level or multivariate modeling | `routes/related.md` |

Match ancestry and genome build to the reference. Genetic correlation is a cohort statistic, not an individual diagnosis or proof of causation. Report uncertainty, sample overlap and reference limitations.

Tested source versions: CBIIT LDSC commit 1f09cf0, HDL 1.4.0+, LAVA 0.1.0+.
