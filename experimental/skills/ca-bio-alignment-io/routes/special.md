# Special formats

```bash
python scripts/alignment_io.py inspect input.sto stockholm summary.json
```

| Case | Read |
|---|---|
| MAF plus-strand coordinates | `references/maf-coordinates.md` |
| Ragged A2M/A3M and match columns | `references/a2m-a3m.md` |
| Stockholm collections too large for memory | `references/stockholm-streaming.md` |
| Format and annotation handling | `references/formats.md` |

For ragged inputs and databases too large for the command, follow the relevant reference instead. A3M reformatting requires the query first.

Done when requested blocks, coordinates, or match columns are obtained.
