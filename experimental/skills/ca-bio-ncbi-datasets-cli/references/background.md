# Scope and version notes

GPTomics source describes NCBI Datasets v2 for genome, gene, ortholog and virus data, with JSON-lines summaries and type-specific `dataformat` conversion. It was checked against CLI 18.37.0; flags, schemas and fields may change. Inspect `datasets --version`, subcommand help and `dataformat tsv <type> --help`; the source notes `dataformat --version` may print undefined. High-volume calls may need an NCBI API key. A zero-record result can have exit status zero. Source examples say normal download validates ZIP checksum, while rehydrate does not validate already-present files; size alone does not prove content integrity. Check expected output and transfer integrity. Raw reads require `bio-sra-data`; other E-utilities queries can use `bio-entrez-search`, `bio-entrez-fetch`, or `bio-batch-downloads`.
