# Design and reporting

GPTomics source distinguishes Welch or rank-sum tests for independent groups, paired tests with ID validation, ANOVA/Tukey or Kruskal-Wallis/Dunn for multiple groups, and mixed models for nested data. Normality pre-testing alone is insufficient to choose a method. Define the comparison family before filtering; Holm controls family-wise error, Bonferroni is conservative and BH controls false discovery rate under its assumptions. Compute adjusted p-values before supplying labels: the source observed ggpubr `stat_compare_means(comparisons=...)` and statannotations Holm/BH labels may show raw values. Source pairwise scripts report rank-biserial r as `2U/(n1*n2)-1`; do not rename it Cliff's delta. Tukey mode reports Hedges' g. Stars are a display convention; preserve exact values, effect size and uncertainty. Show nonsignificant prespecified comparisons or state exclusions. Paired and nested scripts need design-specific effect estimates. Source package version observations are historical; verify local APIs.
