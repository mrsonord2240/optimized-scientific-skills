# Processing and interpretation

GPTomics source describes peak picking, MS2 deconvolution, alignment and gap filling, with different feature tables possible across preprocessing methods. Source console observations refer to version 5.5.260820 and should not substitute for current installed help. DIA mode and its input requirements require run-specific verification; GC-EI has different deconvolution and retention-index considerations from LC. Low detection fraction can make gap-filled values misleading; QC, blank and missingness filters require study-specific decisions. Annotation tags and MS/MS support are not authentic-standard confirmation. The source's commonly cited 0.70 Fill fraction, QC CV 20–30%, D-ratio 0.5 and sample-to-blank 3–5x are starting points rather than universal thresholds. Retain software version, input list, parameters and filtering order.
