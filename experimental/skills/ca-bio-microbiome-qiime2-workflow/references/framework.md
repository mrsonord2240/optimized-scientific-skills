# Framework and provenance

GPTomics source distinguishes semantic type from storage format and describes artifact UUIDs and embedded provenance. A visualization is a terminal presentation object, while an artifact can be used by compatible actions. Exported native files do not carry the artifact wrapper; keep the source artifacts and external metadata required to reconstruct context. The Python Artifact API and CLI access the same framework concepts. A type mismatch should be investigated at the upstream action rather than forced by reimport. Metadata type inference can treat numeric-looking identifiers as numeric covariates. Release, distribution and classifier dependencies change over time; the source's 2026-era names are historical observations, not a current installation recommendation. Verify installed help and the official release documentation before use.
